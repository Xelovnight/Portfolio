Design and development of my bilingual personal portfolio (French/English) to showcase my background, professional experiences, and IT projects.

**Architecture & Technologies**
* Static Site Generation (SSG) utilizing the **Astro 7** framework and **Vite** to ensure optimal performance and lightning-fast load times.
* Data management via Markdown/MDX **Content Collections**, featuring strict data schema validation powered by **Zod**.
* Modular development using **TypeScript** and reusable UI components (layouts, navigation, footer).
* Continuous deployment and hosting managed through **GitHub Pages**.

**User Interface & Experience (UX/UI)**
* Modern, 100% responsive styling built with **Tailwind CSS 4**.
* Advanced customization system: seamless dark/light mode toggle and a dynamic accent color picker.
* Smooth animations: continuous tech stack carousel, interactive modals for project details, and a custom mouse cursor.
* Integration of a fully functional contact form powered by **Formspree**.
