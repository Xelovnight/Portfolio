A collection of completed courses on the OpenClassrooms platform, covering software development, collaborative tools, and IT security best practices.

* **Learn Programming with JavaScript**: Mastery of syntax basics, DOM manipulation, and building interactive scripts.
* **Learn Python Basics**: Variables, control structures, data manipulation (lists, dictionaries), and an introduction to Object-Oriented Programming (OOP).
* **Manage Code with Git and GitHub**: Essential version control commands, branch management, pull requests, and team collaboration best practices.
* **Use ChatGPT to Boost Your Productivity**: Prompting principles, practical use cases (writing assistance, coding), and understanding the model's limitations.
* **Conduct Your Cybersecurity Technology Watch**: Tech watch methodology, identifying reliable sources (ANSSI, CERT-FR), and using aggregation tools (RSS feeds).
* **Protect Your Digital Systems**: Awareness of the 12 ANSSI best practices (strong passwords, data backups, Wi-Fi protection, and anti-phishing vigilance).
