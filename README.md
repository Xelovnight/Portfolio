# Portfolio

Portfolio personnel développé avec Astro pour présenter mon parcours, mes projets, mes certifications et mes coordonnées.

## Aperçu

Ce dépôt contient un site vitrine professionnel avec :

- une page d'accueil avec les derniers projets et expériences
- une section projets détaillée
- une section certifications
- une page à propos
- un formulaire de contact
- une version française et anglaise
- un thème clair/sombre et personnalisation de couleur

## Structure du dépôt

```text
Portfolio/
├── mon-portfolio/        # Application Astro du portfolio
│   ├── src/              # Pages, composants, contenu, styles
│   ├── public/           # Assets statiques
│   ├── package.json      # Scripts du projet
│   ├── astro.config.mjs  # Configuration Astro
│   └── README.md         # README du projet Astro
└── README.md             # README du dépôt
```

## Technologie principale

- Astro
- Tailwind CSS
- TypeScript
- Content Collections
- GitHub Pages pour le déploiement

## Lancement local

```bash
cd mon-portfolio
npm install
npm run dev
```

Le site est ensuite accessible sur :

```text
http://localhost:4321
```

## Construire le projet

```bash
cd mon-portfolio
npm run build
npm run preview
```

## Déploiement

```bash
cd mon-portfolio
npm run deploy
```
